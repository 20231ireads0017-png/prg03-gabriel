# Atividade 16 — JPA com Hibernate

## Descrição

Implementação inicial de persistência de dados no sistema de marcação de consultas do SUS, utilizando JPA, Hibernate e MySQL.

## Localização do código

O código-fonte está no projeto Maven principal:

`ATIVIDADES/prg03gabrielboaventura`

A implementação foi realizada nesse projeto para preservar a estrutura e as funcionalidades das atividades anteriores.

## Funcionalidades implementadas

- Configuração do JPA e Hibernate com MySQL.
- Mapeamento da entidade `Usuario`.
- Criação do repositório `RepositorioUsuarioJPA`.
- Implementação de operações de cadastro, consulta, listagem e exclusão no repositório.
- Criação da interface gráfica `TelaCRUDUsuario`, com tabela de usuários, pesquisa e botões de gerenciamento.
- Testes automatizados de conexão e persistência.
